# arenatrace-legal

iOSアプリ **ArenaTrace** の、公開が必要な文書だけを置くリポジトリ。

App Store Connect はプライバシーポリシーURLとサポートURLの入力を必須に
しているが、アプリ本体のリポジトリは非公開のままにしたい。そのため
公開文書だけをここに分けている。

| ページ | URL |
|---|---|
| プライバシーポリシー | https://kentad1109.github.io/arenatrace-legal/privacy |
| サポート | https://kentad1109.github.io/arenatrace-legal/support |

GitHub Pages（main ブランチのルート）で配信している。
本文の変更はこのリポジトリを直接編集する。
